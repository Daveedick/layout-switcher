# Layout Switcher

[English](README.md) · **Русский**

Нативная Swift-утилита для Mac с Apple Silicon. Одним хоткеем исправляет последнее слово или выделение между английской и русской раскладками. Альтернатива Punto Switcher

**Apple Silicon (arm64) · macOS 14+ · Предварительный выпуск**

Выделите текст или закончите набирать слово, затем нажмите и отпустите **⌥⌘**. Текст переключится между ABC и «Русская – ПК».

## Возможности

- Исправление выделения или последнего набранного слова по настраиваемому сочетанию. Например, `ghbdtn` → `привет`.
- Переключение в обе стороны внутри смешанного выделения. `привет hello` → `ghbdtn руддщ`.
- Работа из строки меню. Иконка в Dock появляется, пока открыто окно Layout Switcher.
- Опциональные запуск при входе в систему и восстановление после аварийного завершения через macOS launchd.

## Установка

1. Скачайте `Layout-Switcher-0.3.3-arm64.dmg` из [предварительного выпуска v0.3.3](https://github.com/Daveedick/layout-switcher/releases/tag/v0.3.3). Там же есть контрольная сумма SHA-256.
2. Откройте образ, перетащите **Layout Switcher** в «Программы» и запустите эту копию.
3. Разрешите приложению «Универсальный доступ» и «Мониторинг ввода» в настройках macOS. Нажмите **«Проверить разрешения»** в приложении или перезапустите его. При необходимости добавьте источники ввода ABC и «Русская – ПК».

Сборка подписана локальной ad-hoc подписью и распространяется без нотаризации Apple. Если macOS покажет предупреждение о неизвестном разработчике, сверьте источник и контрольную сумму. Для проверенной копии можно воспользоваться системной кнопкой **«Всё равно открыть»**, если она доступна. После обновления macOS может повторно запросить оба разрешения.

Сочетание меняется через **«Сочетание клавиш…»**. Пункт **«Включить вход и восстановление после сбоя…»** включает автозапуск и восстановление. Обычное **«Завершить»** закрывает приложение на текущий сеанс и сохраняет настройку входа. В меню также можно отключить автозапуск.

## Приватность и совместимость

Текст обрабатывается на Mac. Для исправления последнего слова приложение держит короткий буфер в памяти и пропускает защищённые поля. При замене выделения в Codex оно временно использует системный буфер обмена и восстанавливает прежнее содержимое, пока буфер всё ещё содержит запись приложения. Утилита не хранит историю ввода и не обращается к сети.

Исправление происходит по хоткею. Перед проверкой завершите Punto Switcher, если он запущен, чтобы сочетания не конфликтовали. Поддержка выделения и замены зависит от редактора и поля. Вставленный из буфера обмена текст или текст, набранный до запуска приложения, можно исправить через выделение.

## Сборка

Установите Swift toolchain и запустите:

```sh
scripts/test.sh
scripts/test-input-sources.sh
scripts/test-clipboard.sh
scripts/build.sh
```

Готовое приложение — `dist/Layout Switcher.app`. Обычная сборка использует готовые иконки. Для отдельной регенерации используйте `python3 scripts/generate-icons.py --app-only` или `--menu-only`.
